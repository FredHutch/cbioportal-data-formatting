# Available Panels on the Fred Hutch instance of cBioPortal

This section of the repository contains a reference table of **available sequencing panels**.  
The table is provided in `available_panels.md`and lists each panel by its stable ID along with a description of the panel.

## File Contents
- **STABLE_ID**: A unique, human-readable identifier for the panel.  
- **DESCRIPTION**: A short description of the panel, typically including the number of genes or the type of sequencing performed.

## Purpose
This table serves as a quick lookup resource for users working with panel data.  
It enables consistent reference to panel names and descriptions.
